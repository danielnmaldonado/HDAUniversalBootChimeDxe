# HDAUniversalBootChimeDxe

HDAUniversalBootChimeDxe is a UEFI DXE driver that plays a startup chime through compatible High Definition Audio (HDA) hardware before the operating system loads. Designed for Clover and OpenCore, it detects audio controllers and codecs at runtime, validates playback routes, supports compatible AppleALC-derived codec layouts, negotiates PCM audio formats, and restores codec state after playback. **💗 Support: [Ko-fi](https://ko-fi.com/olarila) · [PayPal](https://www.paypal.com/donate/?hosted_button_id=AA4QBFJQYW2N2) · [Revolut](https://revolut.me/olarila) · [Remitly](https://remit.ly/pay/danielm2937) · [Mercado Pago](https://mpago.la/2wFPzHP)**.
